# 会話の筋（threads/<id>.js）の書き方

各ファイルは `THREADS.<id> = [ 筋, 筋, 筋 ]`（1人3本以上）。遊ぶたびに種で1本選ばれる。

```js
THREADS.a = [
  { topic: ['パン屋', 'Bakeries'], beats: [
    { her: ['日本語', 'English'], q: 1 /* 相手の文が質問なら */, pause: 1 /* 既読のまま少し間が空く（任意） */, o: [
      { s: 'polite', t: ['こちらの返事', 'My reply'], r: ['相手の返事', 'Her reply'] },
      { s: 'light',  t: [...], r: [...] },
      { s: 'probe',  t: [...], r: [...], min: 2 /* この往復より前に聞くと「いきなり？」で引かれる */, c: 1 /* r に本性のほころびがある時 */ },
    ] },
    ... 8往復以上
  ] },
]
```
- 型 s: polite（丁寧・具体的）/ light（軽いノリ・ツッコミ・短文）/ empathy（共感して広げる）/ praise（褒める・チャラい）/ long（自分語りの長文）/ lewd（下心の誘い）/ doubt（写真を疑う一言）/ probe（本性を探る質問。話題を受けてつなぐ形で）
- 1往復の3択は型が全部ちがう。3つとも、相手の直前の一言（her）への返事として自然に成り立つこと。her が質問なら3つとも答えになっていること
- r は、その子の口調・好み（talk.js の STYLE の like）で返す。刺さらない型には冷めた返し
- 次の往復の her は、どの r の後に来ても自然につながる文。前の話を拾う・覚えている・相手から質問する・話がふくらむ、を混ぜる
- beats[0].her は、こちらの最初の1通（3種）に返事をした後の、相手からの最初の話（あいさつに続く話題の振り）
- 実在の人・店・商品・アプリ・テーマパークの名前は出さない。日英とも自然な会話文
- 点検: `node check_threads.mjs <id>`（NG 0 にする）。表は shots/threads_check.md
